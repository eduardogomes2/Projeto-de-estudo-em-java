Olá a todos! Este é um projeto pessoal destinado ao estudo e revisão de conteudos sobre java,programação orientada a objetos e conceitos basicos de um CRUD 

A primeira versão funciona pelo terminal e permite cadastrar, listar, buscar, atualizar e remover produtos.


## Funcionalidades

- Cadastrar produtos
- Gerar IDs automaticamente
- Listar produtos cadastrados
- Buscar produto por ID
- Atualizar nome, quantidade e preço
- Remover produto
- Validar nomes vazios
- Validar números inteiros e decimais
- Tratar opções inválidas do menu

## Conceitos utilizados

- Classes e objetos
- Encapsulamento
- Construtores
- Getters e setters
- Métodos
- ArrayList
- Scanner
- Estruturas de repetição
- Estruturas condicionais
- Switch
- Tratamento de exceções
- Git e controle de versão
